<h2>一、参数表要反着读</h2>
<p>宣传页上的参数是挑好的，真正要看的是缺失项。没写共享度、没写超量规则，往往就是短处。</p>
<p>拿到参数表先找五样：ASN、类型、共享人数、带宽口径、更换规则。缺两样以上就该谨慎。</p>
<p>销售口头补充的参数也可信，但要求写进订单。只存在于聊天里的承诺，后面很难兑现。</p>
<h2>二、ASN与类型</h2>
<p>ASN登记为运营商，符合住宅特征；登记为托管商或云厂商，就是机房段。</p>
<p>类型还要看分配方式：整条宽带分配、可长期续租的，更接近真实家庭网络。</p>
<p>有些产品宣称住宅，实际是机房段换了标签。查一次归属，比看十行描述快。</p>

<h3>独享要看怎么定义</h3>
<p>有的独享指不与他人共用地址，有的指不与他人共用带宽。两者差别很大，要分别确认。</p>
<p>还有一种情况是同段独享。地址归你，但同网段还有别人，触发关联验证的概率会高一些。</p>
<h2>三、共享度与并发</h2>
<p>共享度直接决定晚高峰表现。同一地址十人同时用，和两三人用，体验完全不同。</p>
<p>并发上限也要问：同时在线设备数、连接数有没有限制，超了是排队还是直接拒绝。</p>
<p>共享度高的产品还容易互相牵连。同址其他人触发风控，你也可能被顺带验证。</p>
<h2>四、带宽与协议</h2>
<p>带宽看两个数：保障值和端口上限。只有端口上限的，实际吞吐要打折看。</p>
<p>协议支持决定接入方式。只给HTTP的，浏览器能用但部分工具不行；支持SOCKS5的更通用。</p>
<p>端口被封是常见问题，签之前问清能否换端口、换端口收不收费。</p>
<h3>端口被封怎么处理</h3>
<p>问清是换端口还是换地址，换的周期多长。支持端口映射的产品，处理起来比换地址快。</p>

<h2>五、地址数量与更换</h2>
<p>按账号数配地址，一个账号一个出口最省心。多人共用一个地址，出问题时很难分清责任。</p>
<p>更换规则写清：多久可换一次、故障换是否免费、换后是否同段。同段更换的意义有限。</p>
<p>地址数量也别一次买满。先按实际在用的账号配，多出来的闲置地址照样计费。</p>
<h2>六、合同与退款</h2>
<p>合同里要有可用率口径、故障响应时间、退款条件三条。都没有的，出问题只能协商。</p>
<p>退款条款注意按剩余天数折算和不支持退款的区别，前者更可控。</p>
<p>续费价格也要写进订单。首月低价加续费翻倍，是这类产品最常见的定价方式。</p>
<h3>续费价要单独问</h3>
<p>首月价与续费价常不同，差价可能翻倍。把续费价写进订单，避免第二个月被动接受。</p>
<h3>先小额后放量</h3>
<p>第一次合作买最小规格，跑满两周再扩。扩的时候按账号逐个加，别一次铺满。</p>
<h2>常见问答</h2>
<h3>美国住宅地址的ASN应该是什么样？</h3>
<p>答：正常应登记为当地运营商。若显示为数据中心或云厂商，说明不是住宅段。</p>
<h3>共享地址能用吗？</h3>
<p>答：能用，但晚高峰表现和账号隔离都弱一些。对稳定性要求高的业务，建议独享。</p>
<h3>带宽标100M实际只有20M正常吗？</h3>
<p>答：如果是共享端口，高峰期打折属常见现象。长期低于标称三成，可要求换机或退款。</p>
<h3>买之前能要求提供测试地址吗？</h3>
<p>答：不少服务商可以给短期测试。拿到测试地址后自己查ASN、测延迟，比看参数表可靠。</p>
